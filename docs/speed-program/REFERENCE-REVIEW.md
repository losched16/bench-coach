# External video reference review

**Limit, stated plainly:** I could not open any Instagram post. The session's network cannot
reach instagram.com. So I could not watch a single video, and **none is approved or verified**. The
only thing I could judge is whether each reference's own title supports the exercise it is attached
to, and whether the title describes something riskier than that exercise allows. Where it does not, I
removed it. Where it plausibly does, I kept it as an "unreviewed" reference, which a person still has
to watch.

The app shows the kept references only inside a collapsed section under each exercise, headed
"Third-party references, not reviewed by BenchCoach", with "Not a recommendation and not approved. Watch
before you use one." Each is credited to its creator and tagged "not yet reviewed". They are never inside the
exercise instructions. A coach can remove or replace any of them per player.

Result: 10 references became 8 (9 different posts become 7). Skater step and infield react-and-throw
now show no reference. A test fails if either removed link comes back or if any kept link is not an
https Instagram reel credited to a creator.

## What a person must do
Watch each of the 7 remaining posts. For each: does it show what its title says, safely, for the age
group; is the creator named correctly; is it acceptable to link to it. Then keep it (it stays "unreviewed"
in the app until you decide how to mark reviewed material, which this feature deliberately does not offer),
or remove it.
